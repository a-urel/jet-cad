# jet_cad_2d_kit_restaurant

The restaurant kit of jet_cad_2d plans: a library of 69 restaurant symbols
(tables, booths, bar, service, commercial kitchen, outdoor and decor) on the
kit contract (`jet_cad_2d_kit`). It depends on the contract only, never on
the plan library.

This README is a stub; the kit's first release brings the full one.
