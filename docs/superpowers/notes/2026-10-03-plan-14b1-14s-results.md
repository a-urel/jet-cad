The first consumer of the floor planner is a Flutter restaurant (POS)
application with a design mode and a selection mode. This branch does the
first two of the umbrella spec's six slices:

- **14b-1, the extraction.** Everything of `apps/floor_planner/lib` but the
  application frame lives in `packages/jet_cad_floor_plan` (`lib/src/`,
  with `editor.dart` for the app and `symbols.dart` /
  `symbol_sources.dart` for symbol authors); the app is the frame (main,
  `FloorPlannerApp`, `DocumentHost`, the platform file dialogs, the exit
  guard, the export flow). Assets and the font are read under their
  `packages/` keys; the package registers family `Roboto` from its own
  bytes (`ensureFloorPlanFonts`), and the app declares the bare family too,
  so the web engine never substitutes Google's Roboto (V-11a).
- **14s, the restaurant symbols.** `SeatingComponent` marks a symbol
  servable and carries its seats; the five dining tables became servable at
  version 2; the loader reads several libraries and merges them; and the
  new package `packages/jet_cad_restaurant_symbols` ships 69 symbols in six
  categories (Restaurant Tables, Booths and Lounge, Bar, Service,
  Commercial Kitchen, Outdoor and Decor), 25 servable, bar stools included
  (the human's decision 4). The app shows furniture and restaurant symbols
  together.

## Found, not fixed

- **F-8 (14s review), half.** A source's read or decode failure is not
  named with the source's name (only a duplicate is). A wrapped error would
  change the failure type the palette's tests assert; left for 14b-2's API.
- **F-9 (14s review).** No widget-level palette test for the restaurant
  categories; the loader-level test (SL9b) and the app wiring test (SL9c)
  cover the order and the sources.
- **F-10 (14s review), the rest.** The piano's curved side is a polyline;
  the lounge set's armchair reaches y = −125; the round dining table was
  renamed "…, 4 seats" with the tag `four`.
- **The font file is in the web bundle twice** (170 KB): once under the
  package's asset key, which every host has, once under the app's font
  declaration. Accepted for now: a host that declares the family could skip
  the asset only if the package stopped declaring it, which would leave
  hosts that do not declare it without the bytes.
- **The L and U bar counters' base points** are their boxes' centres,
  which lie in their open corner and opening.
- **`editor.dart` exports every `src/` file** (plan amendment, F-7).
