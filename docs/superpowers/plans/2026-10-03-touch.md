## Tasks

### Task 1 — touch sessions in the layer (T1, T3, R-1, R-9, R-10)

`ToolPointerEvent.kind` and `reachRadiusWorld` (optional); `TouchPress`
and `Tool.touchPress` (default `lift`); `InteractionLayer`: the touch
session (single / multi), the hold-back in press and lift modes, the
second finger (drop or release, cancel when not idle), no promotion for
touch, touch hovers dropped, `onPointerExit` at a session's end and at
multi, focus on routing, the whole session cleared on deactivate, a held
finger dropped on a tools or active-tool change, `kTouchHoldBack`,
`kTouchPickRadiusPixels`. `RulerFrame` marks precise pointers only.
Tests `test/interaction_layer_touch_test.dart` with a recording tool:
M-14t-5, -6, -8, -9, -10, -14, -16, -20 (layer side), -22, -23, -24,
-25 (layer side).

### Task 2 — the pinch (T2, R-12)

`CameraGestureDetector`: live touches, the pair, baseline on change, pan
then zoom about the new focal, `kPinchMinSpan`, no-op skips. Tests
`test/camera_gesture_touch_test.dart`: M-14t-1..-4, -21, -25 (camera
side).

### Task 3 — finger-sized targets in the select tool (T4, R-2..R-4)

`SelectTool.touchPress = press`; the two-stage pick; `kTouchSlop` for a
touch press; grips and the rotation grip by distance on touch
(`GripCache` distance queries). Run every suite; give the tests that are
mouse clicks by intent `kind: mouse`, named in the commit. Tests:
M-14t-11, -12, -13, -18, -19.

### Task 4 — the selection mode and the drawing tools (T5, T6, R-1, R-11)

`TableSelectTool` and `SymbolPlaceTool`: `touchPress = press`; the long
press timer `kLongPressTimeout − kTouchHoldBack` on touch;
`TablePicker.pick` with the reach on touch. Tests: M-14t-7 (through the
widgets, a pinch during a table drag), -15, -17 (`RoomTool`), -20 (a
polyline survives a pinch), -26.

### Task 5 — the exit

Gates, both web builds, a Chromium CDP-touch smoke of the demo (a pinch
zooms, a touch tap selects and logs, a pinch during a table drag moves
nothing), results note, STATUS, roadmap.
