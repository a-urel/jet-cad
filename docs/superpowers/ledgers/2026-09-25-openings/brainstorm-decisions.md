## Research facts (Explore agent, worktree at 357bea6)
- Closure is spatial only: seeds + before/after reach-neighbours, one hop (RG:103-108). reach(params, toWorld) sees only own params (PS:28-30). generate can paramsOf(any handle) (PS:100-114).
- No explicit object references; an opening storing (host, distance) cannot place its own reach → goes stale when the host moves far; wall's reach is ~2e-6 thick for axis-aligned walls.
- Variable child counts supported (regions too, RG3); matching regions by ordinal; added children get highest handles (06 D12 draw-order cost). One type per handle (RG:76-79).
- No polygon boolean; triangulate: one simple loop, no holes. Straight wall + perpendicular cuts = 1-D split along the wall; hard only near node caps.
- Delete: generic _groupCascade; parametric D8 cleanup nulls the component; no dependents cascade; expander slot taken.
- Startup plan: no 07 walls; doors = jamb lines + leaf line + quarter arc (0x2266CC); windows = 3 lines.
- Grips: single ObjectGripProvider slot (WallGrips) → needs a composite. stretch grip → provider.drag.
- Moving an opening group directly: no per-type move hook.
- No rotate-about-base-point; GripDrag.rotate accepts any pivot.
- 07 for 08: joint overlap can cover an opening cut near a joint; walls chose poché; 07's fixed-three-children draw-order argument breaks if regions split.

## Decisions
1. Symbol: generated by 08's own regeneration (not 09's library); 09 stays a later, soft dependency.
2. Hosting: the engine gains explicit references — a ParametricType declares the handles its params reference (opening → host); the closure adds referrers and referents of each seed. The opening is its own object.
3. Cutting: split the band — the wall draws its band as pieces between its openings (1-D split along a straight wall); openings stay clear of the corner caps; the wall's child count varies.
4. Doesn't fit (near a corner, wall shortened, a wall joins there): keep the stored position; draw clamped into the straight span; if the span is shorter than the width, the wall is uncut and the opening shows its symbol only; diagnostics() names it. No edit refused, nothing lost.
5. Host delete: cascade in the engine, generically — an object whose referenced object is deleted is deleted in the same edit (one undo step), whatever deleted the host.
6. Overlapping openings in one wall: allowed; the wall cuts the union of the gaps; both symbols drawn; diagnostics() names the overlap.
7. Types v1: single-leaf door (width, hinge end, swing side), window (width), plain gap (width); all carry host + position along the wall. No sill/head heights.
8. Tools: one per type — Door on D, Window on N, Gap on G; width in the Selection panel's tool-settings; hover preview; a click on a wall places it centred at the click; a door's swing side = the clicked side of the wall, hinge = the nearer end (flippable later).
9. Editing: Selection panel (width, position along the wall; door: flip hinge, flip swing) + one slide grip at the centre, clamped to the wall; select-tool move/rotate not offered for an opening.
10. Snapping: the existing object snap (F3) and grid, projected onto the wall's centreline, plus on that wall its straight-span ends and the other openings' edges.
11. Sample plan: rebuilt with 07 walls and 08 openings at the same places; its tests (furniture clear of doorways, extents) carried over.
12. Rotate about a chosen base point: its own follow-up branch after 08 (a general transform feature extending 03); not in 08.
13. Symbol colour: ByLayer on layer 0 (follows the paper since fix/post-07); walls stay concrete black.
14. Spike first (throwaway spike/08-openings, never merged; findings note feeds the spec). Spec review skipped, like 07.

## After the spike (note at spike/08-openings 3dd4565, head 634fa7c)
15. Position: distance from the wall's start; when a wall END is dragged (grip), the same edit rewrites its openings' positions so they stay put in world; they move only when the wall moves/rotates as a whole.
16. Centreline: split with the band — one open polyline per piece; the doorway is clean.
17. No-fit opening: its symbol draws just outside the wall's face (never over the band); diagnostics() names it.
18. Obstacles: another wall's T butt or crossing inside the straight part splits it into stretches; an opening clamps into the stretch nearest its position; if none is wide enough it is no-fit.
19. Cascade policy per type: ParametricType declares what happens when an object it references is deleted — cascade (openings) or orphan (keeps, regenerates, reports; for 10's rooms).
Controller rulings (technical):
